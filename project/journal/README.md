# journal/ — the research log (Korean)

The project was done in checkpoints (CP0, CP1, …), one large question each. This folder is the record of how the conclusions in `../README.md` and `../docs/` were reached. A reader who only wants the current design does not need it.

| File | What |
|---|---|
| `CHECKPOINT.md` | one entry per checkpoint: question, plan, expected → actual → lesson, what changed from the plan |
| `cp/CPn.md` | the full record of checkpoint n: rules written before results, environment, commands, tables |
| `cp/cp6_survey.md` | sourced numbers about existing edge chips (CP6) |
| `CP_GUIDE.md` | a plain-language walkthrough of all checkpoints, for readers with no background (Korean, informal) |

The commands in `cp/CP0.md` … `cp/CP30.md` use the layout before CP31 (`src/`, `rtl/`, `results/cpN/`). They run at the git tag `cp30` (see `../legacy/README.md`).
