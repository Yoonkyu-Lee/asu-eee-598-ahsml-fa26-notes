# 연구 파이프라인 지침 (project/)

EEE 598 파이널 프로젝트: **server-blind 커뮤니티의 엣지 노드를 위한 가속기.**
원래 아이디어와 제안서는 `archive/topic-selection/` (IDEA.md, SPEC.md, 제안서 pptx).
**작업 전에 [NORTHSTAR.md](NORTHSTAR.md)를 읽는다.** 무엇을 하든 그 문서와 이어지는 이유를 댈 수 있어야 한다. 에이전트에게 위임하거나 외부 평가를 받을 때도 NORTHSTAR.md를 함께 넘긴다.
이 폴더의 모든 작업은 아래 규칙을 따른다. 예외 없음.

## 1. 단위: 체크포인트 (CP)

- CP 하나 = **큰 문제 하나**를 푼다. 작은 계획 여러 개가 모여 CP 하나가 된다. 잡일이나 작은 단계 하나를 CP로 만들지 않는다.
- CP는 둘 중 하나로 시작한다. 시작할 때 어느 쪽인지 적는다.
  - **목적형**: 답할 질문이 분명하다.
  - **정찰형**: 아이디어를 얻으려는 사전 답사다. "정찰"이라고 명시하고, **무엇을 가늠하는지**를 적는다.
- 무엇을 하는지는 **구현 / 측정 / 디자인 / 데모 / 조사** 중 어느 것인지 표시한다.

## 2. 기록 파일

| 파일 | 내용 | 규칙 |
|---|---|---|
| `CHECKPOINT.md` | CP마다 한 항목, 아래 양식 | **항목당 50줄 미만.** 덧붙이기만 한다. 끝난 항목의 결과를 고치지 않는다 |
| `cp/CPn.md` | 진행 과정, 명령, 환경, 데이터, 표 | 자유 형식. 단 나중에 바로 복기할 수 있게: 무엇을 했고, 어떻게 재현하고, 숫자는 어디서 왔는지 |
| 아티팩트 | CP 계획 다이어그램, 결과 그래프 | **CP마다 최소 하나.** 계획은 그림으로 세운다. 링크를 CHECKPOINT.md에 남긴다 |
| `docs/project/index.html` | 팀원용 영어 현황 페이지 (공개 사이트, 디스코드 고정 링크) | **CP를 마칠 때마다 `team-page` 에이전트(`.claude/agents/team-page.md`)를 "CPn finished"로 부르고, 그 결과를 CP와 같은 커밋에 넣는다.** 쓰는 규칙(파이프라인 용어 빼기, 숫자 대조, 측정/출처/추정 구분)은 에이전트 정의에 있다. 개발 쪽은 페이지를 직접 고치지 않는다 |

## 3. CHECKPOINT.md 항목 양식

```
## CPn — <제목>   (상태: 계획 / 진행 / 완료, 날짜)
- **테마**: 한 줄
- **목적**: 목적형이면 목적. 정찰형이면 "정찰: <무엇을 가늠하는지>"
- **무엇을 하나**: [구현]/[측정]/[디자인]/[데모]/[조사] 표시한 불렛
- **답할 질문**: 불렛
- **계획과 이행**: 간결 요약 + `cp/CPn.md` 링크 + 아티팩트 링크
- **기대 → 실제 → 교훈**: 간단 요약 (세부 숫자는 cp/CPn.md)
- **계획에서 달라진 점**: before → after (있을 때만)
- **다음 CP**: 제목과 한 줄 목적
```

## 4. 설치·구현할 때마다

`cp/CPn.md`의 "환경·의존성" 표에 한 줄씩 남긴다: **무엇을 / 왜 / 기대 / 이후 CP에서의 의존성**.
쓸 수 있는 자원: 이 노트북 (Core Ultra 9 185H, RTX 4080 Laptop), ASU Sol, Apporto ECEE GPU·CAD 랩. 무엇이든 설치·구현해도 되지만 이유를 적는다.

## 5. 측정과 숫자

- 숫자는 **측정값 / 출처 인용 / (추정: 계산식)** 중 하나로 표시한다. 지어내지 않는다.
- 로컬 시간 측정 전에는 사전 점검을 먼저 기록한다: AC 전원, Windows 전원 계획, G-Helper 모드, `nvidia-smi` 전력 제한, 다른 GPU 사용 프로세스. 사용자가 확인하지 않은 조건에서 잰 숫자는 **예비 측정**으로 표시한다.
- 사용자가 GPU로 무언가를 돌리는 중이면 GPU를 쓰지 않는다.

## 6. 파일과 공개

- 코드 `src/`, 측정 결과 `results/`, CP 문서 `cp/`. 논문 PDF는 `refs/`(git 제외).
- 논문 PDF, pptx, 과제 파일은 공개 저장소에 올리지 않는다. 커밋 전에 무엇이 올라가는지 확인한다.
